# Reglas del Proyecto ME-SIM

- **Mobile & Tablet First**: Todo nuevo desarrollo, maquetación o refactorización de interfaz debe ser diseñado y optimizado prioritariamente para dispositivos móviles y tablets. Las vistas de escritorio se adaptarás de forma progresiva (`sm:`, `md:`, `lg:`).
- **Aesthetic Quality**: Mantener la estética premium con paleta oscura/amarilla (`#ffec00`), tipografía legible y microinteracciones fluidas.
